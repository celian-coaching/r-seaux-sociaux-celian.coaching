# LinkedIn

Bannières 1584 x 396 px (exportées en x2), faites avec la charte CD Coaching
(`.claude/instagram/charte/`) : motifs officiels, logo haltère CD, Fugaz One + Oswald,
pastille tracée à la main, éclairs, flèches, ronds, et le logo secondaire (haltère citron dans un rond) à droite. Pas de photo : elle est déjà en photo de profil.

- `banniere-orange.png` : motif logos + pictos blancs sur orange (recommandée)
- `banniere-orange-logo-blanc.png` : idem, logo orange dans un rond blanc
- `banniere-orange-logo-rond-orange.png` : idem, logo blanc dans un rond orange cerclé de blanc
- `banniere-orange-logo-noir.png` : idem, logo noir dans un rond blanc
- `banniere-orange-rond-noir-logo-orange.png` : idem, logo orange dans un rond noir cerclé de blanc
- `banniere-orange-rond-noir-logo-blanc.png` : idem, logo blanc dans un rond noir cerclé de blanc
- `banniere-turquoise.png` : motif logos citron sur turquoise
- `banniere-blanc.png` : motif logos + pictos turquoise sur blanc

Partie gauche laissée libre : la photo de profil LinkedIn s'y pose.

Regénérer : `node linkedin/source/render.js linkedin` (texte dans `source/banniere.html`).
