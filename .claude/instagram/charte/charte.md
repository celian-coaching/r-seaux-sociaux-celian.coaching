# Charte graphique CD Coaching

Source : `charte_graphique_CD_COACHING.pdf` (même dossier).

## Valeurs
- Proximité & convivialité
- Équilibre & bien-être
- Professionnalisme & fiabilité
- Bienveillance

## Identité visuelle
- Aspect manuscrit = pédagogie. Formes arrondies = bien-être, douceur, bienveillance.
- Logo : un haltère qui forme les initiales CD (force, exercice physique).
- Identité modulable : parle autant aux débutants qu'aux profils confirmés.

## Logos
- Principal : haltère CD orange, seul ou avec « CD COACHING » dessous.
- Secondaire (sur fond coloré) : haltère vert citron, dans un rond orange ou turquoise.
- Variations : noir, ou blanc dans un rond orange.

## Couleurs
| Couleur | Hex | RVB | CMJN | Valeur |
|---|---|---|---|---|
| Orange (principale) | #FF721D | 255 / 114 / 29 | 0 / 65 / 89 / 0 | chaleur, convivialité |
| Vert citron | #E0FF20 | 224 / 225 / 32 | 23 / 0 / 100 / 0 | dynamisme, énergie |
| Turquoise | #00DBA0 | 0 / 219 / 160 | 66 / 0 / 53 / 0 | bien-être, équilibre |

Note : le RVB du vert citron dans le PDF (224/225/32) ne correspond pas tout à fait
à #E0FF20 (224/255/32). L'hex fait foi.

## Typographies
- Titres : **Fugaz One** (capitales italiques grasses), souvent en blanc dans une
  pastille arrondie tracée à la main, ou orange sur pastille blanche.
- Sous-titres : Fugaz One.
- Corps de texte : **Oswald**.

## Pictos
- Éclairs, flèches ondulées, traits arrondis en biais, ronds.
- En plein ou en contour, dans les trois couleurs.

## Motifs
- Logo seul répété en diagonale : jaune sur turquoise, blanc sur orange, orange sur blanc.
- Logo + pictos : jaune sur turquoise, blanc sur orange, turquoise sur blanc.
