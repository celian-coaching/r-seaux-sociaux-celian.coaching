# Logo @celian.coaching

Validé le 2026-10-27 : **piste 4** (monogramme C + D emboîtés en haltère, disques détachés).

- `logo-celian-coaching.png` : fond blanc.
- `logo-celian-coaching-transparent.png` : fond transparent.
- `pistes-logo-1-a-4.webp` : les 4 pistes d'origine.
- Couleur : orange `#EE762F`.

Usage : cartons des reels, couvertures des stories à la une, tenues. La photo de profil
reste le visage de Célian. Les fichiers sont recadrés depuis le croquis : à refaire en
vectoriel. Retouche conseillée : des disques plus hauts (environ la moitié de la hauteur
des lettres) pour rester lisibles en petit. Version courte possible : piste 1 (sans disques).

## Déclinaisons couleur (2026-10-27)

Couleurs : orange `#EE762F`, noir `#1A1A1A` (un noir doux plutôt que du noir pur), blanc.

- `logo-orange-transparent.png`, `logo-noir-transparent.png`, `logo-blanc-transparent.png` :
  le logo seul, fond transparent, bords lissés.
- `carre-*.png` : carrés de 1080 × 1080 prêts à poster (6 combinaisons).
- `planche-couleurs.png` : les 6 combinaisons côte à côte, avec le test en rond de 110 px.

Contraste : noir/blanc 18,6 · noir/orange et orange/noir 6,5 · orange/blanc et blanc/orange 2,9.
Les plus percutants : orange sur noir, blanc sur noir, noir sur orange. Blanc sur orange
passe pour un grand logo, pas pour du texte fin.
