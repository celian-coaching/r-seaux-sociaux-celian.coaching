# Logo @celian.coaching

Validé le 2026-10-27 : **piste 4** (monogramme C + D emboîtés en haltère, disques détachés).
Couleurs : celles de `../charte.md` (citron `#e0ff20`, menthe `#00dba0`, orange `#e46d29`,
noir `#141414`, clair `#f4f4f0`).

- `logo-<couleur>-transparent.png` : le logo seul, fond transparent, bords lissés
  (orange, citron, menthe, noir, clair, et blanc pur pour les vidéos).
- `carre-<logo>-sur-<fond>.png` : carrés de 1080 × 1080 prêts à poster.
- `planche-couleurs.png` : toutes les combinaisons, avec le contraste et le test en rond de 110 px.
- `planche-logo.png` : les 9 déclinaisons et la palette sur une seule image (2020 × 2630).
- `logo-celian-coaching.png` : le recadrage d'origine. `pistes-logo-1-a-4.webp` : les 4 pistes.

Combinaisons (contraste) : noir sur citron 16,2 · noir sur menthe 10,2 · noir sur orange 5,7 ;
citron, menthe ou orange sur noir (mêmes valeurs) ; noir/clair 16,7. Comme pour le texte de la
charte : logo noir sur les trois couleurs, logo en couleur sur fond noir. Orange sur clair (2,9)
seulement en grand. Jamais d'orange sur citron ni sur menthe.

Usage : cartons des reels, couvertures des stories à la une, tenues. La photo de profil
reste le visage de Célian. Les fichiers sont recadrés depuis le croquis : à refaire en
vectoriel pour l'impression, avec des disques un peu plus hauts. Version courte : piste 1.
